PDF Editor 使用指南

菜单功能

  • 文件 - 打开、保存 PDF 文件
  • 编辑 - 撤销、重做操作
  • 视图 - 缩放、页面显示设置
  • 工具 - 选择各种编辑工具
  • 帮助 - 查看本帮助文档

工具说明

  • 选择 (↖) - 选择和移动对象
  • 抓手 (✋) - 拖动画布视图
  • 文本 (T) - 添加文本注释
  • 图片 (🖼) - 插入图片
  • 橡皮擦 (🧽) - 擦除标注
  • 高亮 (H) - 高亮文本
  • 下划线 (U̲) - 给文本添加下划线

快捷键

  • Ctrl/Cmd + O - 打开文件
  • Ctrl/Cmd + S - 保存文件
  • Ctrl/Cmd + Z - 撤销
  • Ctrl/Cmd + Y - 重做
  • Ctrl/Cmd + + - 放大
  • Ctrl/Cmd + - - 缩小
  • Ctrl/Cmd + 0 - 重置缩放
  • Delete - 删除选中对象
