# PDF Editor

一款基于 Electron 的桌面 PDF 编辑器，支持文本编辑、OCR 识别、页面管理等完整功能。

## ✨ 功能特性

### 📝 文本编辑
- **文本选择与编辑**：直接点击 PDF 中的文本进行选择和编辑
- **文本属性修改**：支持修改字体、字号、颜色等属性
- **跨行文本处理**：支持段落级别的文本编辑
- **宽字符支持**：完整支持中文、日文、韩文及 Emoji 字符
- **字体保留**：保存时尽可能保留原始字体

### 🔍 OCR 识别
- **扫描件识别**：使用 Tesseract.js 对扫描版 PDF 进行文字识别
- **多语言支持**：支持英文、简体中文等多种语言
- **智能检测**：自动识别 PDF 是否为扫描件

### 📄 页面管理
- **页面旋转**：支持顺时针/逆时针旋转页面
- **页面删除**：支持单页或多页删除
- **页面缩略图**：左侧栏显示所有页面缩略图
- **连续滚动**：支持连续滚动查看所有页面

### 🛠️ 编辑工具
- **选择工具**：选择和移动对象
- **抓手工具**：拖动画布视图
- **文本工具**：添加文本注释
- **图片工具**：插入图片
- **橡皮擦**：擦除标注
- **高亮工具**：高亮文本
- **下划线工具**：为文本添加下划线

### 💾 文件操作
- **合并 PDF**：将多个 PDF 文件合并为一个
- **拆分 PDF**：按页码范围拆分 PDF
- **添加水印**：为 PDF 添加文字水印
- **密码保护**：为 PDF 设置密码保护
- **书签管理**：添加和管理 PDF 书签
- **导出图片**：将页面导出为图片格式

### 🎨 界面功能
- **状态指示器**：实时显示 PDF 可编辑状态
- **缩放控制**：支持放大/缩小/重置缩放
- **撤销/重做**：完整的操作历史管理
- **性能监控**：内置性能监控和指标收集

## 🚀 技术栈

- **Electron 35.0.3**：跨平台桌面应用框架
- **PDF.js 4.0.379**：PDF 渲染和文本提取
- **pdf-lib 1.17.1**：PDF 文档修改和保存
- **Tesseract.js 7.0.0**：OCR 文字识别
- **Jest 29.7.0**：单元测试框架

## 📦 安装

### 环境要求
- Node.js >= 16
- npm 或 yarn

### 安装步骤

```bash
# 克隆项目
cd /path/to/pdf-editor

# 安装依赖
npm install

# 启动应用
npm start
```

## 🎯 使用方法

### 打开 PDF 文件
1. 点击工具栏的"打开"按钮
2. 或直接拖拽 PDF 文件到应用窗口

### 编辑文本
1. 点击 PDF 中的文字即可选中
2. 双击文字直接编辑内容
3. 在右侧面板修改字体、大小、颜色
4. 点击"保存 PDF"完成修改

### 使用 OCR 识别扫描件
1. 打开扫描版 PDF 文件
2. 状态栏会显示"扫描件"标识
3. 系统会自动加载 OCR 引擎
4. 识别完成后可进行文本编辑

### 页面管理
- **旋转页面**：在右侧属性面板点击"左旋"或"右旋"
- **删除页面**：在左侧缩略图中选择页面，点击"删除页"
- **添加书签**：切换到左侧"书签"标签页，点击"添加书签"

### 文件操作
- **合并 PDF**：点击右侧"合并 PDF"按钮，添加要合并的文件
- **拆分 PDF**：点击右侧"拆分 PDF"按钮，输入页码范围
- **添加水印**：点击右侧"添加水印"按钮，输入水印文字
- **密码保护**：在右侧属性面板点击"设置密码保护"

### 快捷键
| 快捷键 | 功能 |
|--------|------|
| Ctrl/Cmd + O | 打开文件 |
| Ctrl/Cmd + S | 保存文件 |
| Ctrl/Cmd + Z | 撤销 |
| Ctrl/Cmd + Y | 重做 |
| Ctrl/Cmd + + | 放大 |
| Ctrl/Cmd + - | 缩小 |
| Ctrl/Cmd + 0 | 重置缩放 |
| Delete | 删除选中对象 |

### 代码架构

#### 主进程 (main.js)
- 管理应用生命周期和窗口
- 处理文件系统操作
- 提供 IPC 通信接口
- 管理 PDF 操作（合并、拆分、水印等）

#### 渲染进程 (renderer.js)
- 管理用户界面交互
- 处理工具选择和属性设置
- 管理页面导航和缩放
- 协调各模块工作

#### PDF 编辑器 (pdf-editor.js)
- 核心编辑功能实现
- 文本提取和渲染
- 鼠标事件处理
- 操作历史管理（撤销/重做）
- OCR 引擎集成
- 文本缓存管理

#### PDF 工具 (pdf-utils.js)
- PDF 文档操作工具集
- 字体嵌入和处理
- 坐标系统转换
- 文件合并/拆分/保护

#### OCR 引擎 (ocr-engine.js)
- Tesseract.js 封装
- 文字识别处理
- 多语言支持
- 识别结果解析

#### 性能监控 (perf-monitor.js)
- 操作性能测量
- 内存使用监控
- 性能日志收集
- 指标报告生成

## 🔐 安全特性

- **Context Isolation**：启用上下文隔离
- **Node Integration 禁用**：防止渲染进程直接访问 Node.js
- **Preload 脚本**：通过安全的 API 桥接暴露必要功能
- **输入验证**：对所有用户输入进行验证

## 📊 性能优化

- **LRU 缓存**：智能管理文本项缓存，限制最大缓存数量
- **懒加载**：使用 IntersectionObserver 按需加载缩略图
- **防抖处理**：对频繁操作进行防抖优化
- **批量渲染**：分批渲染缩略图，避免阻塞主线程
- **内存管理**：定期清理不再使用的资源

## ⚠️ 注意事项

1. **文本编辑限制**：
   - 只能编辑包含真实文本层的 PDF
   - 扫描件需要先进行 OCR 识别
   - 受保护的 PDF 需要先解除保护

2. **字体支持**：
   - 编辑时会尝试保留原始字体
   - 新添加的文本使用系统可用字体
   - 中文字体需要系统安装相应字体

3. **性能建议**：
   - 大文件（>100页）可能加载较慢
   - 建议关闭其他占用内存的应用
   - OCR 识别需要下载语言包，首次使用较慢
